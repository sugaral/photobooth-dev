## 📖 プロジェクト概要

Photobooth AI は、商業施設、セルフ写真館、イベント、観光地写真ブース、結婚式向けに設計された**業務用デュアルモード・スマートフォトブースシステム**です。**PHP 8 業務処理コア**と**Python 独立 AI/CV マイクロサービス**を連携させ、以下の機能を提供します：

1. **クラシックプリクラ写真館**：リアルタイム髪の毛レベルの人物切り抜き、6次元パラメータ美肌補正、アート背景合成、スタンプ・手書きサイン機能。
2. **AI フォト変身**：深層顔特徴抽出と骨格・陰影移行アルゴリズムにより、古風漢服、ウェディングドレス、サイバーパンクなど多彩なスタイルへワンクリック変身。
3. **韓国「人生4カット」連写ワークベンチ**：1×4ストリップ2分割フィルムおよび2×2相紙に対応。連続撮影、1枚再撮影、自由なレイアウト編集、300 DPI 高精細プリント試し刷り機能を完備。

## 🌟 主な特長

1. **🎭 デュアルモード瞬時切り替え**
   - 「クラシックプリクラ」と「AI写真変身」を1台の端末にシームレス統合。
   - ネオブュータリズム（Neo-brutalism）UIデザインにより、直感的なタッチ操作を実現。

2. **⚡ 0ms ゼロフリッカー・シャッターワープ演出**
   - 撮影時のブラックアウトやWindowsデスクトップ・壁紙のチラつきを完全に防止。
   - シャッターと同時にフルスクリーン遮蔽アニメーションを瞬時表示し、バックグラウンドで非同期合成を実行。

3. **✂️ 髪の毛レベルの高精度AI切り抜きエンジン**
   - **BiRefNet-Portrait** および **RMBG-2.0** デュアルモデルを搭載。
   - 切り抜いた人物レイヤーの自由ドラッグ、拡大縮小、微調整、ワンクリックセンタリングをサポート。

4. **💄 6次元リアルタイム美肌レタッチシステム**
   - 美肌、美白、血色感、鮮明度、デカ目、小顔の6項目をパラメータで微調整可能。
   - $C^2$ 連続変形フィールドアルゴリズムを採用し、複数人の集合写真も自然に補正。

5. **🎞️ 韓国「人生4カット」フィルム連写**
   - 撮影リズム案内と単写真再撮影機能を搭載（6枚撮影中4枚をセレクト）。
   - 2"×6" 2連フィルムおよび 4"×6" 4分割相紙にジャストフィット。

6. **🖨️ 工業級 300 DPI 富士フイルムクリスタルプリント試し刷り**
   - 光沢紙、マット紙、パール紙の質感シミュレーション、裁断防止ブリードライン案内を内蔵。

7. **🚀 CUDA & cuDNN 9 自動ダイナミックリンク**
   - NVIDIA RTX 30 / 40 / 50 シリーズGPUを自動認識し、cuDNN 9 DLLを動的注入。GPU非搭載環境でもマルチスレッドCPUで自動動作。

8. **🛡️ 日本語・中国語など Unicode パス完全対応**
   - メモリ内バイナリバイトストリームによる入出力を採用し、非ASCIIフォルダパスによるOpenCVクラッシュを解消。

## 🛠️ クイックスタート

### 1. リポジトリのクローン
```bash
git clone https://github.com/sugaral/photobooth-dev.git
cd photobooth-dev
```

### 2. ワンクリック起動・停止
- **`start.bat`** をダブルクリック：環境検知、ポート解放、Python AIマイクロサービスとPHPサーバーを自動起動し、ブラウザでフォトブース画面を立ち上げます。
- **`stop.bat`** をダブルクリック：すべてのプロセスを安全にシャットダウンし、メモリとカメラリソースを完全に解放します。
