## 🌟 软件介绍

**Photobooth AI** 是一款面向现代化派对、活动展会、商业摄影、文旅快闪店及个人互动场景打造的全功能智能照相亭（Photo Booth）系统。

本软件深度融合了 **传统相馆的高清影像处理能力** 与 **前沿生成式 AI 人像抠图技术**，配备极具视觉吸引力的 Playful Geometric 潮流撞色 UI，支持一键现场拍摄或已有照片上传。用户可在几秒内完成发丝级高精度背景分离，自由缩放人物位置，替换海量主题场景模板，叠加 26 种胶片艺术滤镜，并通过手机扫描二维码极速无线保存原图或连接实体打印机现场成片。

## 🚀 核心功能与特色亮点

### 🤖 1. 双核 AI 智能发丝级抠图与换景引擎
- **双模态 AI 模型自适应**：
  - **BiRefNet-Portrait**：为人像特写、发丝细节极致优化，专长于半身照、大头贴、精细轮廓分割；
  - **RMBG-2.0**：商业级全身站姿与多人合影稳定分离，适应复杂光线与服装材质；
- **60FPS 流光轮廓追踪特效**：抠图完成瞬间自动触发光效沿着人物边缘流转展开，交互极具仪式感与趣味性；
- **双图层自由变换交互**：
  - **人像图层控制**：支持触屏/鼠标自由拖拽人像位置、四角手柄等比例缩放、一键居中重置；
  - **模板图层控制**：支持自定义模板四角缩放、居中对齐与全画幅智能铺满；
- **智能复合图层渲染**：支持内置精选场景模板切换，亦支持上传用户自定义底图背景。

### 🎨 2. 26 款专业复古滤镜与即时视觉渲染
- **0ms GPU 实时视觉反馈**：采用专用 CSS GPU 滤镜直绑技术，点击滤镜瞬间主图即刻完成调色，彻底告别卡顿与白屏；
- **高保真后台图像烘焙**：内建 300ms 智能防抖队列与 GD 图像库，在后台为原片进行无损调色烘焙，兼顾交互流畅与成片画质；
- **丰富风格库预设**：
  - 经典黑白、经典胶片、复古暖调、怀旧质感、冷艳冷调、夏日艳阳；
  - 浅褐暖阳、深褐岁月、鲜艳增强、清透浅淡、水波淡蓝、夜色幽蓝；
  - 柔焦微光、朦胧虚化、金属浮雕、素描轮廓、反色艺术等 26 种经典与艺术效果；
- **侧边抽屉式卡片交互**：直观的缩略图实时预览列表，选中心仪滤镜一目了然。

### 📷 3. 全局多摄像头与快捷设备管理
- **电脑全机位动态枚举**：主界面一键呼出快捷设置面板，自动枚举并列出系统当前连接的所有摄像头设备；
- **实时切换与预览同步**：无需进入繁琐后台，在设置面板中直接下拉切换输入源，并在实时迷你取景框中动态核对画面；
- **镜像翻转（Mirror Flip）**：支持一键开关水平镜像翻转，提供如镜面般的自然自拍方向感；
- **AI 抠图 CPU 运算核心动态调节**：支持在快捷设置面板中自由设定 1~16 核心并发数，修改后即时热生效，无需重启服务；
- **广泛的硬件设备生态**：全面兼容普通免驱 USB 摄像头、内置网络摄像头，以及通过 digiCamControl / gphoto2 接入的专业数码单反相机（DSLR）。

### 📸 4. 多样化摄录模式与图片上传
- **单张定格拍摄**：倒计时提示、实时取景、闪光动效及即时出片；
- **短视频与动图录制**：支持录制短视频与动态 GIF 趣味表情包；
- **拼图连拍（Collage）**：多格艺术拼图模式，支持自定义拍摄间隔与拼图排版样式；
- **上传抠图模式**：支持直接从本地设备选取已有照片载入系统，同样支持全套 AI 抠图换景与滤镜处理。

### 📲 5. 即扫即取与实体照片打印
- **无线扫码取图（QR Code）**：成片界面即时生成专属动态二维码，顾客使用手机直接扫码即可无损下载原图与成片，无需安装任何额外 App；
- **硬件打印机无缝对接**：支持直连热升华照片打印机，可自由设定照片边框、艺术文字、相纸排版、自动打印及防刷重印锁；
- **全屏沉浸式画廊（PhotoSwipe v5）**：内置独立相册浏览系统，支持手势滑动查看、多图缩略图导航与全屏幻灯片放映。

### 🖥️ 6. 现代几何美学与大屏触控优化
- **潮玩几何设计（Playful Geometric）**：活力高饱和色彩配比搭配波点微网格画布，营造欢快愉悦的派对视觉氛围；
- **全端触屏自适应**：超大圆角胶囊按钮、边缘防误触留白、右侧滑动抽屉，完美适配各类自助大屏机、商用触控一体机与平板电脑；
- **待机动态屏保**：支持闲时自动激活画廊轮播或专属宣传视频屏保，有效防止屏幕老化，提升展台吸睛度。

### 🪞 7. AI 智能人像美颜与参数化实时微调引擎 (全新特性)
- **四大核心美颜维度连续可调（0% ~ 100%）**：
  - 👁️ **自然大眼（Big Eye）**：基于虹膜定位与眼眶边缘平滑径向扩展，瞳孔高光清晰，眼睑弧度自然；
  - 🧏 **精致瘦脸（V-Line Face Slimming）**：基于下颌轮廓与两颊关键点，向面部黄金中轴线柔和收缩，紧致轮廓拒绝畸变；
  - 🧖 **质感磨皮（Texture Dermabrasion）**：频域残差分离与保边双边滤波，高效祛除噪点油光与面部杂质，**100% 完整保留健康皮肤肌理与毛孔**，告别塑料假面；
  - ✨ **透亮美白（Radiance Whitening）**：CIELab 亮度空间 S 曲线非线性提亮，配合微妙粉润气色增益，牙齿与背景不发白发灰；
- **多人合影同步美颜（Multi-Face Sync）**：
  - 基于 MediaPipe 478 关键点检测拓扑，支持单人或多达 10 人合影场景，所有人脸同步应用相同的美颜参数矩阵；
- **拍照自动初修与全局快捷配置**：
  - 主页“快捷设置”弹窗新增 AI 美颜开关与 4 项默认强度滑块，现场顾客拍照后自动赋予清爽微量初修，无需反复手动配置；
- **毫秒级防抖实时预览与“按住对比原图”**：
  - 侧边栏一键滑出美颜抽屉，防抖拖拽极速反馈（约 40~60ms），支持长按/轻触瞬间与无修饰原始底片对照；
- **全局紧支集 $C^2$ 连续位移场无缝变形**：
  - 彻底杜绝传统切片贴回导致的脸部矩形接缝与分层错位，发丝刘海、鼻翼眼角与下颌线平滑对齐；
- **全分辨率高保真烘焙（Bake）**：
  - 确认后基于原始底片进行全分辨率无损色彩重采样，打印成片纤毫毕现。

## 📦 环境要求与快速启动

### 1. 运行依赖
| 组件 | 最低版本要求 | 用途说明 |
| :--- | :--- | :--- |
| **PHP** | `>= 8.4.0` | 核心 Web 逻辑、图像处理、模板渲染 |
| **Python** | `>= 3.10.0` | AI 智能人像抠图推理服务 |
| **Node.js** | `>= 20.15.0` | 前端依赖与静态资源构建（如需自行编译） |
| **Web 服务器** | Apache / Nginx / PHP 内置 Server | HTTP 请求分发 |

### 2. 启动服务

#### 启动 Web 主服务
在项目根目录下执行：
```bash
# 启动 PHP 本地开发服务器 (默认端口 8000)
php -S 127.0.0.1:8000
```

#### 启动 AI 智能抠图服务
在另一个终端中启动 Python 推理服务：
```bash
# 启动 AI 人像抠图微服务 (默认端口 8001)
python bin/rembg_service.py
```

#### 访问体验
打开现代浏览器（Chrome、Edge 等），访问：
```
http://127.0.0.1:8000/
```

## 📝 版本更新说明 (Changelog)

### ⚡ 2026.10.15 Update：Windows 中文路径深度兼容与一键启停脚本健壮性升级
- **Windows 中文路径全面兼容（Zero Path Barrier）**：
  - 重构 Python 美颜核心引擎图像 I/O，使用内存二进制流解码（`imdecode` + `frombuffer` / `imencode`）彻底替代原生 `cv2.imread()` 与 `cv2.imwrite()`；
  - 彻底攻克 Windows 平台下 OpenCV 底层 ANSI C `fopen` 无法解析包含中文字符的目录路径（如 `photobooth美颜版`）导致美颜预览与烘焙直接报错 500 的问题；
  - API 与微服务通信全链路强化 `JSON_UNESCAPED_UNICODE` 与 `python -X utf8` 跨进程编码标准，彻底消除 Windows 环境乱码隐患。
- **一键启停脚本规范与容错升级 (`start-photobooth.bat` & `stop-photobooth.bat`)**：
  - 全面规范脚本换行符为 Windows 原生 CRLF（无 BOM 的 UTF-8），彻底根除 `cmd.exe` 解析 LF 脚本引起的 `for /f` 循环语法报错与无法关闭进程问题；
  - `start-photobooth.bat` 新增 Composer `vendor/autoload.php` 缺失智能检测与自愈安装逻辑，提升初次部署与离线运行体验；
  - 移除 Windows 下不支持的 `PHP_CLI_SERVER_WORKERS=4` 参数，消除平台启动 warning；
  - `stop-photobooth.bat` 升级 8000 (Web) 与 8001 (AI) 双端口及孤儿进程安全精准释放。
- **美颜实时预览与原图对比体验优化**：
  - 前端抽屉打开时自动构建底片参照，保障首次拖动滑块或长按“按住对比原图”时对比基准完全一致；
  - 优化预览生成与请求防抖机制，单帧实时预览处理耗时低至 70~150ms。
