## 📖 프로젝트 개요

Photobooth AI는 무인 셀프 포토 스튜디오, 쇼핑몰 포토부스, 팝업 이벤트, 한복/웨딩 테마 사진관을 위해 제작된 **산업용 듀얼 모드 스마트 포토부스 시스템**입니다. 현대적인 **PHP 8 비즈니스 코어**와 독립 **Python AI/CV 마이크로서비스**를 융합하여 다음 기능을 제공합니다:

1. **클래식 스튜디오 촬영**: 실시간 머리카락 수준 인물 누끼 분리, 6차원 파라메트릭 뷰티 보정, 아트 배경 합성, 스티커 및 네온 손글씨 서명.
2. **AI 마법 화보 변신**: 딥러닝 기반 안면 특징 추출 및 골격 조명 마이그레이션 알고리즘을 통해 한복, 웨딩드레스, 사이버펑크 등 다양한 콘셉트로 원클릭 변신.
3. **한국 인생네컷(Life4Cuts) 연사 워크벤치**: 1×4 스트립 2열 필름 및 2×2 포토 프레임 연사, 단일 컷 즉시 재촬영(6컷 중 4컷 선택), 300 DPI 고정밀 인화 교정창 완비.

## 🌟 핵심 장점

1. **🎭 듀얼 모드 즉시 전환**
   - 하나의 키오스크에서 [클래식 스티커 사진]과 [AI 화보 변신] 모드를 유연하게 통합 운영.
   - 직관적인 네오 브루탈리즘(Neo-brutalism) 인터페이스 카드로 고객이 손쉽게 선택 가능.

2. **⚡ 0ms 제로 플리커 셔터 전환 연출**
   - 촬영 셔터 작동 시 화면 깜빡임이나 윈도우 바탕화면이 노출되는 현상을 완벽 차단.
   - 셔터 작동 즉시 풀스크린 마스크가 팝업되며 백그라운드에서 비동기 합성을 안전하게 처리.

3. **✂️ 고정밀 AI 인물 누끼 분리 엔진**
   - **BiRefNet-Portrait** 및 **RMBG-2.0** 듀얼 모델 탑재.
   - 인물 레이어의 자유 드래그, 비율 유지 확대/축소, 위치 미세 조정 및 원클릭 중앙 정렬 지원.

4. **💄 6차원 실시간 뷰티 보정 엔진**
   - 피부 보정, 미백, 혈색, 선명도, 눈 크기, V라인 턱 보정을 슬라이더로 정밀 조절.
   - 단체 사진에서도 최대 10인까지 자연스럽고 왜곡 없는 동시 보정 지원.

5. **🎞️ 인생네컷(Life4Cuts) 맞춤 연사 워크벤치**
   - 촬영 템포 카운트다운 가이드와 단일 컷 재촬영 시스템 구축.
   - 2"×6" 듀얼 스트립 인화지 및 4"×6" 규격에 최적화된 300 DPI 레이아웃 생성.

6. **🖨️ 300 DPI 상업용 인쇄 교정 및 재질 시뮬레이션**
   - 유광 인화지, 무광 벨벳, 펄 재질 시뮬레이션 지원 및 인쇄 재단 안전선 안내.

7. **🚀 CUDA & cuDNN 9 자동 DLL 주입 브릿지**
   - NVIDIA RTX 30 / 40 / 50 시리즈 GPU 자동 감지 및 하드웨어 가속 지원; 비GPU 환경에서는 멀티스레드 CPU로 자동 전환.

## 🛠️ 빠른 시작

### 1. 소스코드 복제
```bash
git clone https://github.com/sugaral/photobooth-dev.git
cd photobooth-dev
```

### 2. 원클릭 실행 및 종료
- **`start.bat`** 더블 클릭: 환경 감지, 포트 정리, Python AI 마이크로서비스 및 PHP 서버 자동 실행 후 브라우저 포토부스 화면 오픈.
- **`stop.bat`** 더블 클릭: 모든 백그라운드 프로세스를 안전하게 종료하고 GPU 및 카메라 리소스 완전 해제.
